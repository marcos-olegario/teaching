## English

This directory collects the study guides and tutorials I prepare for students who are starting to work with software and tools used in astroparticle physics and extensive air shower research. **Most of the material is written in Portuguese**, since it was made for undergraduate students in Brazil.

### Contents

| Folder | Topic |
|---|---|
| [`how-to-use-conex/`](how-to-use-conex/) | How to install and use **CONEX**, a fast one-dimensional air shower simulation code |

### Feedback

Found a mistake, an outdated command, or something unclear? Please let me know by email at **marcos.olegario@usp.br**, or open an issue in this repository.
